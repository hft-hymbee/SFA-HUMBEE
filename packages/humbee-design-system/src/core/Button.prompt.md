# Button

The primary Humbee action button. Filled/outlined/text variants across 5 colours; brown (`primary`) is the default.

```jsx
<Button variant="filled" color="primary" label="Create PO" leftIcon={<Icon name="Add" size={20} color="#fff" />} />
<Button variant="outlined" color="neutral" label="Cancel" />
```

40px tall (medium) / 32px (small), 8px radius, weight 600, no text-transform. `loading` shows a spinner and disables.
