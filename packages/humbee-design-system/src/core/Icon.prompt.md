# Icon

Humbee glyph renderer — draws an icon from the built-in registry by name (mirrors the source IconReusable). Use for all product iconography.

```jsx
<Icon name="ShoppingCartOutlined" size={24} color="#995A00" />
```

Names include: Dashboard, HomeOutlined/HomeFilled, ShoppingCartOutlined, InventoryOutlined, PoOutlined, CreatePoOutlined, InvoiceOutlined, PaymentOutlined, DispatchPlanOutlined, RewardsOutlined, SearchOutlined, NotificationsOutlined, SettingsOutlined, LogoutOutlined, ProfileOutlined, PersonRounded, CurrencyRupee, Add, Minus, Close, Edit, Delete, CheckCircle, Warning, InfoFilled, KeyboardArrowDown, KeyboardArrowRight, ArrowRight, FilterList, Sort, DownloadOutlined, Menu. Read `ICON_NAMES` for the full list. Unknown names render nothing.
