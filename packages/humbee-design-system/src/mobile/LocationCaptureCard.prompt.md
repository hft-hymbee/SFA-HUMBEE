# LocationCaptureCard

`LocationCaptureCard` shows live GPS state on Punch in/out (locating / captured / error) with a `MapPreview` tile, address, coords, accuracy and timestamp. MapPreview is a non-interactive placeholder tile — swap for a real map when wired.

```jsx
<LocationCaptureCard status="captured" address="MG Road, Bengaluru" time="9:41 AM" />
```
