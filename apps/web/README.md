# Humbee Web

Production Next.js frontend for Humbee SFA.

## Commands

```bash
pnpm dev
pnpm build
pnpm lint
```

## Responsibilities

- Own production routes, app logic, and frontend integrations.
- Consume approved UI from `packages/humbee-design-system`.
- Treat `apps/sfa-prototype` as reference/spec input, not as production source.
